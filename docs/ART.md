# 美术需求清单

> 给美术同学/外包的交接文档。游戏当前是 **320×180 像素风**（实际渲染内部高度 200，宽度按窗口比例），所有画面元素都是代码里用字符点阵手绘的。如果你的美术资源到位，我会把它们接进 `js/sprites.js` 的精灵管线，替换掉现在的占位图。

---

## 一、技术规格（必须先对齐，否则接不进去）

| 项目 | 要求 |
|---|---|
| 格式 | **PNG，带透明通道**，不要 JPG |
| 缩放 | **1x 原始像素**，不要放大、不要抗锯齿（放大我可以无损做） |
| 色彩 | 每个精灵建议 ≤ 8 色；全项目建议统一 **32 色调色板** |
| 描边 | 统一用深色描边（`#0a0a12` 附近），不要用纯黑 |
| 光影 | 左上光、右下暗，保持一致 |
| 背景 | 透明，**不要画地板/阴影**（阴影由代码画） |
| 对齐 | 角色脚底对齐图片底边；武器/特效以中心对齐 |

**交付方式（两种都行）**：

1. **单文件**：`hero_idle.png`、`hero_walk1.png`… 放进 `assets/`，我按文件名接。
2. **图集**：一张 `sprites.png` + 一份 JSON（每帧 `{name, x, y, w, h}`）。这种方式更好维护。

## 五、优先级（如果时间有限，按这个顺序做）

1. **玩家 hero / hero2**（占屏时间最长）
2. **敌人 slime / skel / bat**（出现频率最高）
3. **地面纹理**（一换整个画面观感就变）
4. **首领 boss / boss2**
5. **装备与技能图标**
6. 其余

---

## 六、验收标准

- 在 1x 下像素清晰，边缘不发虚
- 轮廓在深色地板上能一眼分辨（当前地板是 `#12121c` 附近）
- 同一屏里 100+ 个敌人时，主角仍然最显眼（建议主角用更亮的主色）
- 每个资源不超过 **4KB**（整包控制在 500KB 内，保证纯网页秒开）
